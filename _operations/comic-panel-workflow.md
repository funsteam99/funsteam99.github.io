# 漫畫分格工作流

2026-10-14：已發布作品優先。分格資料與本機預覽完成，尚未部署。

## 不同版型使用同一流程

`_data/comic_panel_specs.json` 是逐張定稿的座標與處理規格，不能以作品名稱套固定網格。每張包括：原圖路徑、SHA256、原圖尺寸、刊頭矩形、各格矩形與順序、替代文字、局部改號矩形、補充圖。矩形採 `[左, 上, 右, 下]`，右與下不包含在裁切中；局部改號座標相對於該格。

每份定稿都須目視確認，並保留所有正文、對話、地圖、頁底及知識內容。跨格內容不能硬切。刊頭嵌入首格時，沿沒有文字的水平邊界拆開，原首格正文仍是內容第 1 格。

跨格對話等非矩形區域使用 `pieces`：每片指定來源 `box` 與輸出位置 `at`，配合 `canvas_size`。輸出白色底圖上按原像素貼入，不生成或重畫內容，需填 `reason` 說明。每片來源及輸出都驗證不重疊；所有來源像素仍須保留。飛機第二格的跨界對話、蝴蝶右下告示牌已採此方式，不能為了矩形硬切文字。

`kind` 可為 `header`、`panel` 或 `supplement`。刊頭與補充圖不編格號；有格號者從 1 連續排列。分數式格號改為單一號碼，實驗步驟、地圖號碼、科學數值及分數保留。刊頭原有首格號僅在原編號範圍內遮除，不另加「刊頭」文字；正文首格以網頁格號標示。

## 製作與驗證

1. 新圖先取得核准定稿，記錄來源雜湊與尺寸，人工標記每格範圍。
2. 執行 `python scripts/build_comic_panels.py`。重建階段目前使用 Windows 的 Arial 與微軟正黑體字型；字型只用於局部標籤及本機對照圖，不隨網站載入。
3. 腳本保留原圖，輸出 PNG 與無損 WebP 至 `assets/images/panels/<作品 ID>/`，輸出網站資料至 `_data/comic_panels.json`。
4. 腳本檢查：來源雜湊未改、裁切在邊界內、所有来源像素覆蓋且無重疊、格號連續、裁切區域外零像素變動、無損 WebP 與 PNG 一致。改號區域內的字樣仍須人工目視驗收。
5. 查看工作區 `output/comic-panels/qa/` 的原圖標框與 `verification.json`，以及本機預覽。逐篇檢查裁切框是否沿自然邊界、是否切斷文字或共用裝飾。像素覆蓋通過不代表閱讀版面通過。
   執行 `python scripts/preview_comic_panels.py` 可重建通用本機內容預覽（工作區 `output/comic-panels/index.html`），預設 375px 閱讀欄，包含全部作品入口、未改原圖與裁切框對照。這個工具只讀分格資料，不修改網站頁面。
6. 執行 `python scripts/build_comic_panels.py --verify`，不修改圖片；檢查既存資產及 PNG 雜湊與資料一致。
7. 頁面使用 `{% include comic-reader.html id='作品 ID' %}`，front matter 設 `extra_reader_css: /assets/css/comic-reader.css`。原有標題、網址、集數錨點與科學正文保留。

## 發布銜接

目前西遊 1～3 集、聲音、蝴蝶、四季、電池與飛機共 8 篇已製作本機分格版；媽媽的時間銀行目前只有封面，保留單圖。待發作品及 `serial-assets/publish-due.ps1` 尚未修改。先預覽與驗收已發布內容，再接入待發素材；沿用原日期，未完成分格的到期作品可先按現行流程發布，之後補分格。

發布前以 PR 建置產物核對完整網站，包含首屏、圖片路徑、原圖入口、手機寬度與既有補充文字。保留原圖及部署前提交，遇到漏字或錯序可復原。不能以內容預覽代替正式 Jekyll 建置驗收。
